# Archive

Documentation from RendMD v1, kept for provenance rather than reference. Most of
it describes an architecture that no longer exists: the four-theme system, the
single-document store, the AI assistant, and the phase-based build process that
produced them.

For current documentation see [../ARCHITECTURE.md](../ARCHITECTURE.md) and
[../DECISIONS.md](../DECISIONS.md).
